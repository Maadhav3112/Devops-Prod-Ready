# Unit Tests

Place your application unit tests in this folder.

## Examples by stack

| Stack | Typical files |
|-------|----------------|
| Node.js / Jest | `*.test.js` or `*.spec.js` |
| Python / pytest | `test_*.py` |
| Go | `*_test.go` |
| Java / JUnit | `*Test.java` |

## Run

```bash
# Node
npm test

# Python
pytest tests/unit -q

# Go
go test ./...
